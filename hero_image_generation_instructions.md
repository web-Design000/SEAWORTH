# SEAWORTH 網站內頁封面圖 — 生圖與放置指令

給執行的 AI:請針對下面每一項，用給定的 prompt 生成一張圖片，並把檔案**存成指定的絕對路徑**（檔名跟路徑都必須完全一致，不要自己改檔名）。網站的 HTML 已經預先指向這些路徑了，檔案存到位就會自動生效，不需要再修改任何程式碼。

## 圖片規格（每一張都要套用）

- **尺寸／比例**：橫幅寬幅，建議 2400×1200px 或同比例（約 2:1，可接受 16:9 ~ 21:9 之間），寬度至少 2200px
- **格式**：JPG
- **風格後綴**（每個 prompt 後面都要加上）：
  `cinematic documentary photography, wide banner composition, moody golden-hour or twilight lighting, deep ocean navy and teal tones (#00495B / #162B40), shallow negative space in lower-left area for text overlay, ultra realistic, shot on 35mm, no text, no logos, no watermark, no illustration, no cartoon`
- **負面提示（negative prompt，如果工具支援）**：
  `cartoon, illustration, 3d render, clipart, cheesy stock photo, visible readable text, visible ship name plates, low quality, oversaturated neon colors, watermark, deformed hands, extra limbs`
- 構圖上，畫面下方或左下角要留一塊相對暗、相對乾淨的區域（因為網站會在那疊白色文字標題）
